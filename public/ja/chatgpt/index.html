仕組みとよくある質問

出口 IP とは？

サイトにアクセスしたとき、相手から見えるアドレスです。自宅では通常プロバイダのものですが、VPN、プロキシ、社内ネットワーク、iCloud プライベートリレーを使うと、通信を中継する側のアドレスになり、別の都市や国にあることもあります。出口によって接続先サーバーが決まるので、速度も出口で決まります。

出口が複数あるのはなぜ？

ルールで振り分けるプロキシや VPN は、一部の通信を別ルートに流します。IPv4 と IPv6 が別のネットワークから出ることもあり、ビデオ通話で使う WebRTC（UDP）は多くのプロキシを通りません。独立した複数のチェックに同時に問い合わせ、見つかった出口をすべて表示します。

遅延はどう測っていますか？

ブラウザが各サービスと本物の HTTPS 接続を開きます。最初のリクエストは接続確立（DNS、TCP、TLS）用で、別に表示し集計しません。その後同じ接続を再利用して計測し、中央値を表示します。Wi‑Fi、プロバイダ、プロキシを含む、端末からサービスの最寄りサーバーまでの往復時間で、アプリが実際に体感する遅延です。

ping と結果が違うのはなぜ？

ping は ICMP を使いますが、ブラウザからは送れず、ネットワークによっては通常の通信と扱いが異なります。HTTPS の計測は普段のアプリと同じ経路を通ります。サーバーがリクエストに応答する分、ping より数ミリ秒高くなるのが普通です。

犬のスピードの意味は？

爆走 ≤ 30 ms：同じ都市。ダッシュ ≤ 80 ms：同じ地域。トコトコ ≤ 150 ms：ほぼ何でも快適。おさんぽ ≤ 300 ms：ゲームや通話で気になる。おひるね > 300 ms：遠いか混雑。戻らず：5 秒以内に接続できず、ここからは利用できない状態です。2 ms 未満なら伝説の 1ms 犬。

データはどこかに送られますか？

いいえ。すべてのリクエストはブラウザからテスト対象のサービスへ直接送られます。1ms.dog は静的なページを配信するだけで、結果を受け取ることはありません。前回の結果はこのブラウザ内にだけ保存され、変化があれば犬が教えてくれます。
