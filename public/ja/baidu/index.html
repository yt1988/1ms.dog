仕組みとよくある質問

あなたの回線から 百度 はどれくらい速い？

比べたいときは、トップページで 百度 とほかの地域の定番サービスをまとめて測れます：哔哩哔哩、微信、抖音。

出口 IP とは？

サイトにアクセスしたとき、相手から見えるあなたのアドレスです。自宅なら通常は契約しているプロバイダのものです。VPN、プロキシ、会社のネットワーク、iCloud プライベートリレーを使うと、通信を中継する側のアドレスになり、別の都市や別の国にあることもあります。サービスはこのアドレスを見てつなぐサーバーを決めるので、速度にも影響します。

直接接続とプロキシの出口が両方出るのはなぜ？

多くのプロキシや VPN がスプリットトンネル（分流）で、サイトによって経路を変えるからです。一部のサイトは直接つなぎ、それ以外はプロキシを通します。そのため 1 つの IP チェックでは、そのチェックが通った経路しか見えません。そこで 1ms.dog 自身、中国本土のサイト、Cloudflare、ip.sb、ipinfo.io、IPv4 専用と IPv6 専用のチェック、WebRTC（UDP）に同時に問い合わせ、ネットワークごとにまとめて、出口ごとに直接接続かプロキシかを表示します。ふだんあなたの国からつながらないサービスが応答した場合は、どのチェックにも見えていない出口があることもお知らせします。

遅延はどう測っていますか？

ブラウザが各サービスと実際の HTTPS 接続を開きます。最初のリクエストは接続の準備（DNS の問い合わせ、TCP と TLS のハンドシェイク）にだけ使い、別に表示して集計には入れません。そのあと同じ接続で何回か測り、中央値を表示します。つまり、端末から Wi‑Fi、プロバイダ、プロキシを通って、サービスの最寄りサーバーまでを往復する時間です。アプリを使うときに実際に感じる遅延と同じです。

ping と結果が違うのはなぜ？

ping は ICMP という仕組みを使いますが、ブラウザからは送れません。また多くのネットワークは ICMP を通常の通信とは別に扱うので、ping が速くてもアプリが速いとは限りません。HTTPS での計測は、ふだん使うアプリと同じ経路を通ります。サーバーがリクエストに答える分、ping より数ミリ秒高く出るのが普通です。

犬のスピードの意味は？

爆走 ≤ 30 ms：同じ都市くらい。ダッシュ ≤ 80 ms：同じ地域。トコトコ ≤ 150 ms：ほとんど何でも快適。おさんぽ ≤ 300 ms：ゲームや通話で遅れを感じます。おひるね > 300 ms：遠いか、経路が混雑しています。戻らず：5 秒以内につながらず、ここからは使えません。2 ms 未満なら伝説の 1ms 犬が出てきます。

データはどこかに送られますか？

測定結果が私たちに送られることはありません。遅延テストのリクエストは、ブラウザから測定先のサービスへ直接届きます。出口 IP を調べるときは、ブラウザが 1ms.dog といくつかの公開 IP チェックサービスに問い合わせるので、そこにはあなたの IP が見えます。IP を調べる以上、これは避けられません。前回の結果はこのブラウザの中にだけ保存し、回線の変化を知らせるのに使います。結果がブラウザの外に出るのは、シェアしたときと問題を報告したときだけです。シェア用リンクに入るのは国と遅延で、チェックを入れたときだけ都市とネットワークが加わります。IP アドレスは入りません。1ms.dog では、リンクを短くし、チャットアプリのリンクプレビュー用に結果の画像を保存します。
