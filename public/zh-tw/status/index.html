原理與常見問題

服務狀態（東京視角）

我們在東京的伺服器每小時測一遍每個服務，方法和你的瀏覽器一樣：先發一個請求建立連線，再在同一條連線上計時幾次。這裡是那台伺服器的數字，不是你的：和你自己的測試對比，就能看出一個服務慢，是大家都慢，還是只有你的線路慢。首頁每條軌道上的細線，就是這台伺服器測到的 24 小時中位數。

什麼是出口 IP？

出口 IP 就是網站看到的你的位址。在家上網時，它通常屬於你的電信業者；如果用了 VPN、代理、公司網路或 iCloud 私密轉送，它就屬於幫你轉送流量的那一方，可能在別的城市，甚至別的國家。服務會依出口 IP 把你分配到某台伺服器，所以它也直接影響你的速度。

為什麼同時有直連出口和代理出口？

因為很多代理和 VPN 會分流（依網站選路：有些網站直連，其他網站走代理）。只問一個檢測點，就只看得到其中一條路。所以我們同時問好幾個：1ms.dog 自己、中國大陸的網站、Cloudflare、ip.sb、ipinfo.io、只走 IPv4 和只走 IPv6 的檢測，以及 WebRTC（走 UDP）。再把結果依網路歸併，列出每個出口，標明是直連還是代理。如果平常從你所在地區連不上的服務卻連上了，我們也會提醒你：還有一個出口沒被檢測到。

延遲是怎麼測的？

你的瀏覽器會和每個服務建立一條真實的 HTTPS 連線。第一次請求只用來建立連線（查詢 DNS、TCP 交握、TLS 加密交握），會分開顯示，不算進結果；接著在同一條連線上再送幾次請求計時，取中位數。所以你看到的，是從你的裝置經過 Wi‑Fi、電信業者和代理，到這個服務最近一台伺服器的一次往返，也就是你平常用 App 時實際感受到的延遲。

為什麼和 ping 的結果不一樣？

ping 用的是 ICMP 協定，瀏覽器送不出去；而且很多網路處理 ICMP 的方式和一般流量不同，ping 快不代表用起來快。HTTPS 計時和你平常用的 App 走同一條路。數字通常會比 ping 高幾毫秒，因為伺服器要多處理一次請求。

狗狗的速度等級是什麼意思？

閃電狗 ≤ 30 ms：差不多在同一個城市。飛奔 ≤ 80 ms：同一個地區。小跑 ≤ 150 ms：幾乎做什麼都夠用。散步 ≤ 300 ms：玩遊戲、視訊通話會覺得慢。趴著睡 > 300 ms：距離太遠，或線路壅塞。沒叼回來：5 秒內沒連上，代表從這裡無法使用。低於 2 ms，會解鎖傳說中的 1ms 神犬。

我的資料會被傳到哪裡？

測速結果不會傳給我們。延遲測試的請求都由你的瀏覽器直接送到被測的服務；查出口 IP 時，瀏覽器會詢問 1ms.dog 和幾個公開的 IP 查詢服務，它們當然會看到你的 IP，這本來就是查 IP 的方式。上次的結果只存在你的瀏覽器裡，用來告訴你網路有沒有變化。只有在你按下分享或回報問題時，結果才會離開瀏覽器：分享連結裡帶著國家和延遲，勾選後才加上城市和電信業者，從不包含 IP 位址；在 1ms.dog 上，連結會被縮短，並儲存一張結果卡片，當作聊天軟體裡的連結預覽。完整測試結束後，你的瀏覽器還會和 1ms.dog 在東京的伺服器互傳幾則很小的訊息，測一下到那裡的往返時間；那台伺服器不記錄日誌。
