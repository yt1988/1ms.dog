原理和常见问题

服务状态（东京视角）

我们在东京的服务器每小时测一遍每个服务，方法和你的浏览器一样：先发一个请求建立连接，再在同一条连接上计时几次。这里是那台服务器的数字，不是你的：和你自己的测试对比，就能看出一个服务慢，是大家都慢，还是只有你的线路慢。首页每条轨道上的细线，就是这台服务器测到的 24 小时中位数。

什么是出口 IP？

出口 IP 就是网站看到的你的地址。在家上网时，它通常属于你的宽带运营商；用了 VPN、代理、公司网络或 iCloud 专用代理，它就属于替你转发流量的那一方，可能在别的城市，甚至别的国家。服务会按出口 IP 把你分到某台服务器，所以它也直接影响你的速度。

为什么同时有直连出口和代理出口？

因为很多代理和 VPN 会分流（按网站选路：有的网站直连，其他网站走代理）。只问一个检测点，就只能看到其中一条路。所以我们同时问好几个：1ms.dog 自己、国内站点、Cloudflare、ip.sb、ipinfo.io、只走 IPv4 和只走 IPv6 的检测，以及 WebRTC（走 UDP）。再把结果按网络归并，列出每个出口，标明是直连还是代理。如果平时从你所在地区连不上的服务却连上了，我们也会提醒你：还有一个出口没被检测到。

延迟是怎么测的？

你的浏览器会和每个服务建立一条真实的 HTTPS 连接。第一次请求只用来建立连接（查 DNS、TCP 握手、TLS 加密握手），单独显示，不算进结果；之后在这条连接上再发几次请求计时，取中位数。所以你看到的，是从你的设备经过 Wi‑Fi、运营商和代理，到这个服务最近一台服务器的一次往返，也就是你平时用 App 时实际感受到的延迟。

为什么和 ping 的结果不一样？

ping 用的是 ICMP 协议，浏览器发不了；而且很多网络对 ICMP 的处理和普通流量不同，ping 快不代表用起来快。HTTPS 计时和你平时用的 App 走同一条路。数字通常比 ping 高几毫秒，因为服务器要多处理一次请求。

狗狗的速度等级是什么意思？

闪电狗 ≤ 30 ms：相当于同城。飞奔 ≤ 80 ms：同一地区。小跑 ≤ 150 ms：几乎干什么都够用。散步 ≤ 300 ms：打游戏、视频通话会觉得慢。趴窝 > 300 ms：离得太远，或者线路拥堵。没叼回来：5 秒内没连上，说明从这里访问不了。低于 2 ms，会解锁传说中的 1ms 神犬。

我的数据会被发到哪里？

测速结果不会发给我们。延迟测试的请求都由你的浏览器直接发给被测的服务；查出口 IP 时，浏览器会去问 1ms.dog 和几个公开的 IP 检测服务，它们自然会看到你的 IP，这本来就是查 IP 的方式。上次的结果只存在你的浏览器里，用来告诉你网络有没有变化。只有你点了分享或报告问题，结果才会离开浏览器：分享链接里带着国家和延迟，勾选后才加上城市和运营商，从不包含 IP 地址；在 1ms.dog 上，链接会被缩短，并保存一张结果卡片，作为聊天软件里的链接预览。完整测试结束后，你的浏览器还会和 1ms.dog 在东京的服务器互发几条很小的消息，测一下到那里的往返时间；那台服务器不记日志。
